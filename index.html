Le classeur Excel fait foi. L'appli garde ses données en ligne (Supabase), sur PC comme sur téléphone.

Importer le classeur

Exporter

À déposer dans 03_SUIVI\IMPORTS_APP : la tâche du dimanche reporte tes saisies dans le classeur.

Installer l'application sur le téléphone

  1. iPhone : ouvre l'adresse de l'appli dans Safari, touche Partager ⬆︎ puis « Sur l'écran d'accueil ».
  2. Android : ouvre-la dans Chrome, menu ⋮ puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
  3. Connecte-toi une fois : la session reste ouverte. Les données sont les mêmes sur tous les appareils.
